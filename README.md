# KassArrayDA

## Описание

Инструмент обработки выгрузок ОФД в составе пакета инструментов KassArray (54-ФЗ).

Подробное описание приложения доступно на [отдельной странице](https://adslbarxatov.github.io/KassArrayDA).

Начиная работу с этим продуктом, Вы полностью соглашаетесь с данной Политикой и принимаете её!*
