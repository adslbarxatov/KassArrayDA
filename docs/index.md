## Общие сведения об инструменте KassArrayDA
> Data analyzer, только Windows

Приложение позволяет обрабатывать выгрузки фискальных документов из личных
кабинетов операторов фискальных данных. Является альтернативой платным опциям
ОФД, реализующим тот же функционал, а также неисправным обработчикам данных,
встечающимся у некоторых поставщиков услуг.

В текущей версии доступен импорт данных из файлов `.xlsx`, полученных путём
экспорта фискальных документов (без фильтров или с фильтрацией, не исключающей
кассовые чеки и чеки коррекции) из личного кабинета ОФД. Поддерживаются
форматы экспорта следующих операторов:
- Первый ОФД
- Платформа ОФД
- ОФД Ярус

При этом доступна возможность загрузить сразу несколько выгрузок (например,
из нескольких фискальных накопителей). Приложение автоматически их комбинирует,
сортирует чеки по дате формирования и исключает все остальные типы документов,
а также чеки, у которых совпадают дата, время и фискальный признак. В связи
с этим рекомендуется самостоятельно контролировать, чтобы выгрузки относились
к одному и тому же владельцу.

> Не рекомендуется менять или пересохранять содержимое файлов `.xlsx`, выгружаемых 
> из личного кабинета ОФД. Корректный импорт изменённых файлов не гарантируется

Экспорт статистики доступен в следующих вариантах:
- Полный экспорт кассовых чеков с исключением полей, значения которых равны нулю
во всех документах выгрузки
- Экспорт сумм по каждому дню за вычетом возвратов
- Экспорт сумм по каждому месяцу за вычетом возвратов
- Экспорт сумм по каждому году за вычетом возвратов
